## 👋 Bienvenid@ 

¡Bienvenid@ al repositorio de **Programación de 1º de DAW**! 🎓

En este repositorio iremos guardando los diferentes ejercicios, prácticas
y proyectos realizados durante el curso.

La idea es utilizar Git y GitHub para aprender a trabajar con código,
controlar versiones y mantener nuestros proyectos organizados. 🧑‍💻

| 📌 Bloque | 📝 Contenido |
|---|---|
| 🔢 Fundamentos | Variables, tipos de datos, operadores... |
| 🔀 Control de flujo | `if`, `else`, `switch`... |
| 🔁 Bucles | `for`, `while`, `do-while`... |
| 📦 Arrays | Vectores y matrices |
| 🧩 Métodos | Creación y uso de métodos |
| 🏗️ POO | Clases, objetos, herencia... |
| 📁 Ficheros | Lectura, escritura y gestión de archivos |
| 🌳 Git | Ramas, commits, merge, push, pull... |
| ☕ Java | Prácticas y ejercicios realizados en Java |
...
